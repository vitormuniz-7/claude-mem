# Registro de alterações no WordPress (vitindoclio.com.br)

Toda chamada à API REST (ou comando WP-CLI) que **altera** algo no site é registrada aqui.
Leituras (GET) não entram. Conteúdo novo nasce sempre como rascunho (`status: draft`);
publicação só com aprovação explícita do Vitor. Antes de mexer em tema, plugin ou
configuração: backup pelo painel da Hostinger + confirmação.
